# Как поднять сервер Chameleon

Сервер ставится одной командой. Скрипт задаст несколько вопросов, на которые можно
просто нажимать Enter, и в конце покажет готовую ссылку для подключения и QR-код.

## Что нужно

- VPS с Linux, лучше всего Ubuntu 22.04 или новее либо Debian 12 или новее.
- Доступ к нему по SSH под пользователем `root` или с `sudo`.
- Минимум 1 ГБ памяти и 5 ГБ на диске. Если памяти мало, скрипт сам создаст файл подкачки.

Если вы купили VPS, хостер прислал IP-адрес и пароль. Подключитесь к серверу, подставив
свой IP (в Windows 10 и 11 это работает в обычном терминале):

```bash
ssh root@ВАШ_IP
```

## Какой способ выбрать

| | Docker | Прямо на VPS |
|---|---|---|
| Для кого | Подходит большинству | Если не хотите ставить Docker |
| Какие системы | Большинство Linux | Только Debian и Ubuntu |
| Что появится в системе | Docker и два контейнера | Служба `chameleon`, .NET и nginx |

Если сомневаетесь, берите Docker.

## Установка

Выполните на сервере **одну** из команд.

**Через Docker:**

```bash
curl -fsSL https://raw.githubusercontent.com/13cyberpunk02/Chameleon/master/scripts/install-docker.sh | sudo bash
```

**Прямо на VPS:**

```bash
curl -fsSL https://raw.githubusercontent.com/13cyberpunk02/Chameleon/master/scripts/install-native.sh | sudo bash
```

Установка занимает несколько минут: сервер собирается на месте.

### Что спросит скрипт

| Вопрос | Что ответить |
|---|---|
| Адрес сервера | Enter: скрипт определит IP сам |
| Порт | Enter: будет 443, как у обычного HTTPS |
| Домен маскировки (SNI) | Enter или адрес популярного сайта |
| Сайт-прикрытие | Enter: посторонние увидят простую заглушку. Если указываете свой, нужен адрес с обычным HTTP, например `example.com:80` |
| Имя первого клиента | Например, `Телефон` |

### Что вы получите

В конце скрипт покажет:

- **ссылку** вида `chameleon://...` и её QR-код;
- **токен** для входа в веб-панель;
- команды для просмотра журнала и перезапуска.

> Ссылка содержит личный ключ клиента, токен даёт полный доступ к панели. Не публикуйте
> их. Ссылка сохраняется в `/etc/chameleon/first-client.txt`.

Если порт закрыт в панели управления хостера, откройте там входящий TCP на порт 443.
Файрвол `ufw` на самом сервере скрипт настроит сам.

## Как подключиться

1. Установите приложение Chameleon на компьютер или телефон.
2. Скопируйте ссылку. На телефоне можно отсканировать QR-код любым сканером и скопировать текст.
3. В приложении на вкладке «Серверы» вставьте ссылку из буфера обмена.
4. Нажмите кнопку подключения.

**Каждому устройству нужна своя ссылка:** новых клиентов создают в веб-панели, кнопка
«Создать клиента».

## Веб-панель

Панель не открыта в интернет, поэтому заходить в неё нужно через SSH-туннель. На **своём
компьютере** выполните команду и оставьте окно открытым:

```bash
ssh -L 8080:127.0.0.1:8080 root@ВАШ_IP
```

Откройте в браузере `http://127.0.0.1:8080` и введите токен. Забыли токен? Он лежит на сервере:

```bash
sudo grep API_TOKEN /etc/chameleon/*.env
```

## Обновление

Запустите ту же команду установки ещё раз. Ключи, клиенты и настройки сохранятся,
повторно вопросы задаваться не будут.

## Управление

| Действие | Docker | Прямо на VPS |
|---|---|---|
| Журнал | `docker logs -f chameleon` | `journalctl -u chameleon -f` |
| Перезапуск | `docker restart chameleon` | `systemctl restart chameleon` |
| Настройки | `/etc/chameleon/docker.env` | `/etc/chameleon/server.env` |

После правки настроек в Docker запустите команду установки ещё раз (простого `docker restart`
мало), а на VPS выполните `systemctl restart chameleon`.

## Удаление

Скачайте скрипт и запустите с параметром `--uninstall`, указав тот скрипт, которым ставили:

```bash
curl -fsSL https://raw.githubusercontent.com/13cyberpunk02/Chameleon/master/scripts/install-docker.sh | sudo bash -s -- --uninstall
```

Ключи и база клиентов останутся. Как удалить и их, скрипт напишет в конце.

## Установка без вопросов

Значения можно передать заранее, а параметр `--yes` отключит вопросы. Для установки прямо
на VPS есть ещё `--no-panel`: так не ставятся nginx и панель.

```bash
curl -fsSL https://raw.githubusercontent.com/13cyberpunk02/Chameleon/master/scripts/install-docker.sh \
  | sudo CHAMELEON_SNI=www.microsoft.com CHAMELEON_CLIENT_NAME=Телефон bash -s -- --yes
```

## Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| `Порт 443 уже занят` | На нём работает другая программа. Отключите её или укажите другой порт |
| Клиент не подключается | Проверьте, что порт открыт в панели хостера, и посмотрите журнал |
| Подключается, но нет трафика | Откройте панель: блок «Стоит проверить» покажет короткие сессии. Прохождение блокировок зависит от оператора и не гарантировано |
| `Сервер не запустился` | Скрипт покажет журнал: причина обычно в его последних строках |
| Сборка оборвалась, в журнале `Killed` | Не хватило памяти. Добавьте подкачку или возьмите VPS побольше и запустите команду ещё раз |

## Что важно знать

- Скрипт создаёт самоподписанный сертификат: для работы этого хватает. Для лучшей маскировки
  нужен настоящий домен и сертификат, см. [DEPLOY.md](DEPLOY.md).
- Подключаться могут только клиенты, созданные на сервере (включён `CHAMELEON_ALLOWLIST=1`).
- Подробная ручная настройка описана в [DEPLOY.md](DEPLOY.md).
